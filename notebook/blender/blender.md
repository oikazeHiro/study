## 通用操作
| 快捷键 | 功能说明 |
|--------|----------|
| `空格键` | 打开搜索菜单 |
| `F3` | 打开命令搜索 |
| `Ctrl+S` | 保存文件 |
| `Ctrl+O` | 打开文件 |
| `Ctrl+N` | 新建文件 |
| `Ctrl+Z` | 撤销操作 |
| `Ctrl+Shift+Z` | 重做操作 |
| `Tab` | 切换物体/编辑模式 |
| `~` | 视图切换菜单 |
| `/` | 进入/退出局部视图 |
| `Shift+C` | 重置3D游标和视图 |
| `Ctrl+Alt+Q` | 切换四视图布局 |
